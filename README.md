# Colored Bird Mod

Adds six colored birds with natural behaviors and realistic sounds to Minecraft.

## Features

- Six colored bird variants (blue, green, red, white, yellow, black)
- Natural behaviors and animations for each bird variant
- Realistic environmental sounds for each bird variant
- Immersive soundscape with unique daytime and nighttime sounds

## Requirements

- Minecraft Bedrock Edition
- Fabric Loader
- Fabric API

## Installation

1. Download the mod from the releases page.
2. Place the mod in your Minecraft Bedrock Edition mods folder.
3. Enable the mod in your Minecraft settings.

## Usage

Once installed, the birds will spawn naturally in the world. They will have natural behaviors, animations, and realistic sounds.

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the mod.
